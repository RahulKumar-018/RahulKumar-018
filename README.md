### [Drishti-Himalaya](https://github.com/RahulKumar-018/drishti-himalaya)

*Hazard-aware route planning for Himalayan mountain roads*

**Stack:** React 18 · Vite · Leaflet.js · FastAPI · Python · Pydantic v2 · Shapely · Open-Meteo

**What it does:**
Routes between Himalayan destinations are split into ~250m segments. Each segment is scored across four independent risk factors — rainfall intensity, terrain slope, proximity to historical hazard events, and route exposure — using a weighted MCDA composite formula. The output is a color-coded risk map: 🟢 LOW · 🟡 MODERATE · 🟠 HIGH · 🔴 CRITICAL.

**Engineering highlights:**
- Multi-criteria decision analysis (MCDA) scoring engine with configurable factor weights
- Full-stack architecture: React frontend with `/api` proxy to FastAPI backend
- Dual-mode system: demo mode (fully offline, synthetic data) + live mode (OSRM/OpenRouteService + Open-Meteo)
- Typed Python throughout with Pydantic v2 schemas as data contracts
- Segmentation pipeline using Haversine + Shapely for pure NumPy geospatial computation
- Pytest test suite for segmentation and risk logic

**Links:** [Repository](https://github.com/RahulKumar-018/drishti-himalaya)
